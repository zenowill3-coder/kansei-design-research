# Attitude 态度层感性词汇库

## A-1 长期信赖

**Long-term Trust**

用户经过持续使用后，认为产品稳定、可靠、值得依赖。

| 关键词       | 释义               |
| --------- | ---------------- |
| **信赖**​   | 长期相信产品稳定可靠。      |
| **可靠**​   | 认为产品可以持续完成承诺。    |
| **踏实**​   | 拥有和使用它让人有长期安全感。  |
| **怀疑**​   | 对产品长期表现缺少信心。     |
| **失望**​   | 长期表现低于期待，产生负面判断。 |
| **不可依赖**​ | 认为产品不能长期承担重要任务。  |

## A-2 价值认同

**Value Identification**

用户认为产品表达的价值观、生活态度与自己一致。

| 关键词     | 释义                 |
| ------- | ------------------ |
| **认同**​ | 觉得产品表达的价值与自己一致。    |
| **同频**​ | 感到产品气质和自己的生活态度相近。  |
| **共鸣**​ | 产品触发用户较深层的价值回应。    |
| **违和**​ | 产品表达的价值与用户自我认知不匹配。 |
| **抵触**​ | 用户对产品价值表达产生排斥。     |
| **空洞**​ | 产品看似有理念，但缺少真实感。    |

## A-3 身份表达

**Identity Expression**

用户愿意通过产品表达自己的品味、身份、圈层或专业性。

| 关键词      | 释义                 |
| -------- | ------------------ |
| **自豪**​  | 愿意展示产品，并从中获得正向身份感。 |
| **有品位**​ | 产品能表达用户审美和选择能力。    |
| **专业**​  | 产品让用户显得更懂行、更有能力。   |
| **尴尬**​  | 用户不愿展示，担心他人评价。     |
| **失配**​  | 产品与用户身份或场景不匹配。     |
| **俗气**​  | 产品表达过度，削弱身份品质。     |

## A-4 生活方式嵌入

**Lifestyle Integration**

产品能够长期进入用户生活，成为生活方式的一部分。

| 关键词      | 释义              |
| -------- | --------------- |
| **融入**​  | 产品自然进入日常生活，不突兀。 |
| **习惯**​  | 用户长期形成固定使用依赖。   |
| **适合我**​ | 产品与用户生活节奏和偏好匹配。 |
| **负担**​  | 长期拥有或使用带来压力。    |
| **入侵**​  | 产品过度占据生活空间或注意力。 |
| **可替代**​ | 产品缺少独特意义，容易被替换。 |

## A-5 情感依恋

**Emotional Attachment**

用户在长期拥有中，对产品形成陪伴、珍惜、记忆和关系感。

| 关键词      | 释义               |
| -------- | ---------------- |
| **依恋**​  | 对产品形成稳定的情感连接。    |
| **珍惜**​  | 用户愿意保留、维护和认真对待它。 |
| **有故事**​ | 产品承载个人经历、关系或记忆。  |
| **冷淡**​  | 长期使用后仍没有情感连接。    |
| **无感**​  | 产品没有留下情绪印记。      |
| **易弃**​  | 用户不介意丢弃或更换它。     |

## A-6 审美耐久

**Aesthetic Longevity**

用户经过长期观看和使用后，仍然认为产品值得欣赏。

| 关键词     | 释义               |
| ------- | ---------------- |
| **耐看**​ | 长期观看后仍然顺眼、不厌倦。   |
| **经典**​ | 形式不依赖短期潮流，具有持久性。 |
| **克制**​ | 表达不过度，长期相处不疲劳。   |
| **过时**​ | 长期看显得落后于时代。      |
| **厌倦**​ | 初期吸引后很快失去兴趣。     |
| **浮夸**​ | 表达过度，难以长期接受      |

## A-7 拥有正当性

**Ownership Worthiness**

用户认为购买、拥有和持续使用这个产品是值得的、合理的。

| 关键词     | 释义                |
| ------- | ----------------- |
| **值得**​ | 用户认为拥有它有充分理由。     |
| **划算**​ | 价格、价值和体验之间关系合理。   |
| **必要**​ | 用户认为它对自己的生活有持续意义。 |
| **后悔**​ | 拥有后认为选择不值得。       |
| **不值**​ | 感到投入与获得不匹配。       |
| **多余**​ | 认为产品缺少持续存在的必要。    |

## A-8 产品人格稳定性

**Product Personality Stability**

智能硬件在长期使用中形成稳定、可识别的产品性格。

| 关键词     | 释义                 |
| ------- | ------------------ |
| **温和**​ | 产品长期表现出不打扰、低压的性格。  |
| **可靠**​ | 产品人格稳定，不反复、不失常。    |
| **活泼**​ | 产品长期表现出积极、有生命力的性格。 |
| **反复**​ | 产品性格不稳定，前后体验不一致。   |
| **冷漠**​ | 产品缺少长期关系感和回应温度。    |
| **做作**​ | 人格表达刻意，不自然。        |

## A-9 品牌气质承载

**Brand Character Embodiment**

产品是否长期、稳定地承载品牌气质和审美立场。

| 关键词      | 释义               |
| -------- | ---------------- |
| **一贯**​  | 产品与品牌长期气质保持一致。   |
| **有辨识**​ | 产品让人容易记住并识别品牌特征。 |
| **同频**​  | 用户感到品牌气质与自己相近。   |
| **割裂**​  | 产品表现与品牌印象不一致。    |
| **模糊**​  | 产品缺少清晰的品牌性格。     |
| **虚假**​  | 品牌表达让人觉得不真诚。     |
