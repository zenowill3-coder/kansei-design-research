# Sensation 感知层感性词汇库

## S-1 形态轮廓感知

**Form & Silhouette Perception**

由产品的外形边界、体量、线条、曲率和姿态带来的直接视觉印象。

### S-1A 轮廓性格

| 关键词         | 释义                    |
| ----------- | --------------------- |
| \*\*圆润\*\*  | 边界柔和，攻击性低，容易接近。       |
| \*\*凌厉\*\*  | 线条锐利，方向感强，具有速度或力量暗示。  |
| \*\*柔和\*\*  | 形态过渡自然，视觉刺激较低。        |
| \*\*生硬\*\*  | 形态转折突兀，缺少自然过渡。        |

### S-1B 体量轻重

| 关键词         | 释义               |
| ----------- | ---------------- |
| \*\*轻盈\*\*  | 体量显得轻、薄、悬浮或不笨重。  |
| \*\*厚重\*\*  | 体量显得扎实、有重量和存在感。  |
| \*\*笨重\*\*  | 体块显得迟钝、累赘、不灵活。   |
| \*\*单薄\*\*  | 形体缺少支撑感和稳定存在感。   |

### S-1C 姿态动势

| 关键词         | 释义                 |
| ----------- | ------------------ |
| \*\*稳定\*\*  | 重心清楚，视觉上不易倾倒或失衡。   |
| \*\*动感\*\*  | 姿态具有方向性、速度感或运动趋势。  |
| \*\*呆板\*\*  | 姿态缺少变化，显得僵硬和迟缓。    |
| \*\*失衡\*\*  | 重心或比例不稳，带来不安定印象。   |

## S-2 比例尺度感知

**Proportion & Scale Perception**

由产品尺寸、长宽高比例、人体关系和空间占用带来的视觉尺度感。

### S-2A 比例秩序

| 关键词         | 释义                  |
| ----------- | ------------------- |
| \*\*均衡\*\*  | 各部分比例协调，没有明显突兀感。    |
| \*\*修长\*\*  | 长宽高关系拉伸，显得轻快、有延展感。  |
| \*\*紧凑\*\*  | 体积被有效收束，显得精炼、不松散。   |
| \*\*失调\*\*  | 局部比例不协调，破坏整体秩序。     |

### S-2B 人体贴合

| 关键词         | 释义                   |
| ----------- | -------------------- |
| \*\*亲手\*\*  | 尺寸、握持或接触关系让人愿意上手。    |
| \*\*合身\*\*  | 产品尺度与身体关系自然、不过大或过小。  |
| \*\*隔手\*\*  | 产品与手或身体之间有距离感，不易亲近。  |
| \*\*压迫\*\*  | 尺度、体量或距离让人产生被逼近感。    |

### S-2C 空间占用

| 关键词         | 释义               |
| ----------- | ---------------- |
| \*\*精巧\*\*  | 占用空间小，但仍具有完整感。   |
| \*\*大气\*\*  | 尺度舒展，具有开阔和存在感。   |
| \*\*局促\*\*  | 结构拥挤，缺少呼吸感。      |
| \*\*侵占\*\*  | 占用过多空间，显得强势或打扰。  |

## S-3 材质触感感知

**Material & Tactile Perception**

由材料表面、软硬、冷暖、粗细、弹性和接触反馈带来的直接身体感受。

### S-3A 表面细腻度

| 关键词         | 释义                  |
| ----------- | ------------------- |
| \*\*细腻\*\*  | 表面触感均匀、精细，没有明显粗糙感。  |
| \*\*光滑\*\*  | 表面摩擦低，触摸顺滑。         |
| \*\*粗粝\*\*  | 表面颗粒明显，触感粗糙。        |
| \*\*毛糙\*\*  | 表面处理不精细，带有廉价或未完成感。  |

### S-3B 材料温度感

| 关键词         | 释义               |
| ----------- | ---------------- |
| \*\*温润\*\*  | 材质触感柔和、温暖，有亲近感。  |
| \*\*清冷\*\*  | 材质偏冷静、克制，有距离感。   |
| \*\*冰冷\*\*  | 触感过冷，容易产生疏离或不适。  |
| \*\*闷滞\*\*  | 材质触感不透气、不清爽。     |

### S-3C 软硬弹性

| 关键词         | 释义               |
| ----------- | ---------------- |
| \*\*柔软\*\*  | 触感有缓冲，降低身体压力。    |
| \*\*坚实\*\*  | 触感有支撑，不松散、不塌陷。   |
| \*\*松垮\*\*  | 材质支撑不足，显得不稳或廉价。  |
| \*\*僵硬\*\*  | 触感缺少弹性，身体适配性弱。   |

## S-4 色彩光影感知

**Color & Light Perception**

由色彩、明度、饱和度、透明度、反射和发光方式带来的视觉氛围。

### S-4A 色彩温度

| 关键词         | 释义                |
| ----------- | ----------------- |
| \*\*温暖\*\*  | 色彩带来亲近、柔和、生活化感受。  |
| \*\*冷静\*\*  | 色彩带来理性、克制、清醒感受。   |
| \*\*燥热\*\*  | 色彩刺激过强，容易产生烦躁感。   |
| \*\*阴冷\*\*  | 色彩过冷或过暗，带来疏离感。    |

### S-4B 明度纯度

| 关键词         | 释义                |
| ----------- | ----------------- |
| \*\*明快\*\*  | 色彩明度高，显得轻松、清爽。    |
| \*\*清透\*\*  | 色彩或材质具有通透、干净感。    |
| \*\*浑浊\*\*  | 色彩灰脏，缺少清晰感。       |
| \*\*刺眼\*\*  | 明度或饱和度过高，视觉刺激过强。  |

### S-4C 光影气质

| 关键词         | 释义                 |
| ----------- | ------------------ |
| \*\*柔光\*\*  | 光线过渡柔和，不产生压迫。      |
| \*\*锐光\*\*  | 光线边界清晰，带来锋利或科技印象。  |
| \*\*幽暗\*\*  | 光线不足，带来隐秘或压抑感。     |
| \*\*杂乱\*\*  | 光源、反光或灯效缺少秩序。      |

## S-5 声音与机械反馈感知

**Sound & Mechanical Feedback Perception**

由产品开合、按压、运行、提示和机械动作产生的直接听觉与触觉印象。

### S-5A 声音质地

| 关键词         | 释义                |
| ----------- | ----------------- |
| \*\*清脆\*\*  | 声音干净、短促，有明确反馈感。   |
| \*\*柔和\*\*  | 声音低刺激，不尖锐、不突兀。    |
| \*\*尖锐\*\*  | 高频明显，容易产生不适或紧张。   |
| \*\*嘈杂\*\*  | 声音复杂、噪声多，破坏感官舒适。  |

### S-5B 机械阻尼

| 关键词         | 释义                |
| ----------- | ----------------- |
| \*\*扎实\*\*  | 按压、旋转、开合时有稳定支撑感。  |
| \*\*顺滑\*\*  | 动作连续，摩擦和停顿感低。     |
| \*\*卡滞\*\*  | 动作不连贯，有阻塞或顿挫感。    |
| \*\*松散\*\*  | 反馈缺少支撑，显得不稳。      |

### S-5C 反馈洁净度

| 关键词         | 释义                 |
| ----------- | ------------------ |
| \*\*干净\*\*  | 声音或机械反馈简洁，没有多余噪声。  |
| \*\*克制\*\*  | 反馈不过度，不抢占注意力。      |
| \*\*拖沓\*\*  | 反馈延迟或余音过长，显得迟缓。    |
| \*\*干扰\*\*  | 声音或反馈过强，打断用户感受。    |

## S-6 感官一致性感知

**Sensory Coherence Perception**

由形态、色彩、材质、声音、光影之间是否统一所形成的整体直觉印象。

### S-6A 多感官统一

| 关键词         | 释义                      |
| ----------- | ----------------------- |
| \*\*协调\*\*  | 各感官线索相互支持，没有冲突。         |
| \*\*统一\*\*  | 形态、CMF、声音、光效共同指向同一种气质。  |
| \*\*违和\*\*  | 不同感官线索相互冲突。             |
| \*\*拼贴\*\*  | 元素组合松散，缺少整体性。           |

### S-6B 新鲜与熟悉

| 关键词         | 释义                 |
| ----------- | ------------------ |
| \*\*新鲜\*\*  | 形式带来新的感知刺激，但仍可理解。  |
| \*\*熟悉\*\*  | 符合用户对该类产品的基本认知。    |
| \*\*陌生\*\*  | 形式超出经验过多，难以快速理解。   |
| \*\*陈旧\*\*  | 形式语言缺少新意，显得过时。     |

### S-6C 形式亲近性

| 关键词         | 释义                |
| ----------- | ----------------- |
| \*\*亲近\*\*  | 产品外显线索让人愿意靠近和接触。  |
| \*\*低压\*\*  | 产品存在感温和，不造成心理压迫。  |
| \*\*冷漠\*\*  | 形式过于疏离，缺少接近意愿。    |
| \*\*强势\*\*  | 形式存在感过强，给人被支配感。   |
