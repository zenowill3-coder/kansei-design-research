# Emotion 情绪层感性词汇库

## E-1 安心与守护

**Reassurance & Protection**

产品在使用过程中带来的稳定、保护、可依靠的情绪状态。

| 关键词      | 释义                |
| -------- | ----------------- |
| **安心**​  | 使用中感到稳定、不担心。      |
| **被保护**​ | 感到产品在主动避免风险或照顾自己。 |
| **稳妥**​  | 过程有把握，不容易出问题。     |
| **不安**​  | 使用中始终担心状态或结果。     |
| **脆弱**​  | 感到产品不够可靠，容易出错或损坏。 |
| **悬空**​  | 缺少心理落点，不知道是否安全。   |

## E-2 松弛与舒缓

**Relaxation & Ease**

产品在使用过程中降低心理紧绷，让用户进入更自然、舒缓的状态。

| 关键词     | 释义               |
| ------- | ---------------- |
| **松弛**​ | 使用中身体和心理压力降低。    |
| **舒缓**​ | 节奏温和，情绪逐渐放松。     |
| **安静**​ | 产品存在感低，不打扰用户状态。  |
| **紧绷**​ | 使用中保持警惕，难以放松。    |
| **急促**​ | 节奏过快或反馈过强，让人被催促。 |
| **压抑**​ | 使用氛围沉重，情绪难以舒展。   |

## E-3 陪伴与回应

**Companionship & Response**

产品在使用中呈现出温和存在感，让用户感到被回应、被陪伴。

| 关键词      | 释义                 |
| -------- | ------------------ |
| **陪伴**​  | 产品像温和存在，持续陪在用户身边。  |
| **被回应**​ | 用户动作或状态被产品及时感知和回应。 |
| **被理解**​ | 产品表现出适应用户需求或状态的能力。 |
| **冷淡**​  | 产品反馈机械、生硬，缺少情绪温度。  |
| **孤立**​  | 使用中感觉只能独自处理，缺少支持。  |
| **失联**​  | 产品状态和用户之间缺少联系感。    |

## E-4 愉悦与趣味

**Pleasure & Playfulness**

产品在使用过程中带来的轻微快乐、正反馈、趣味或惊喜。

| 关键词     | 释义               |
| ------- | ---------------- |
| **愉悦**​ | 使用过程带来轻松的正向情绪。   |
| **有趣**​ | 产品行为或反馈带来趣味感。    |
| **惊喜**​ | 使用中出现超出预期的正向体验。  |
| **乏味**​ | 过程平淡，缺少情绪反馈。     |
| **尴尬**​ | 产品表达不自然，让用户感到不适。 |
| **幼稚**​ | 趣味表达过度，显得不成熟。    |

## E-5 掌控与自由

**Control & Freedom**

用户在使用过程中感到能够主导节奏、状态和关系，而不是被产品支配。

| 关键词     | 释义                |
| ------- | ----------------- |
| **掌控**​ | 用户感到自己能主导产品状态和节奏。 |
| **自由**​ | 使用中选择空间大，不被过度限制。  |
| **从容**​ | 使用节奏可控，不慌乱、不被催促。  |
| **失控**​ | 产品状态超出用户理解或控制。    |
| **被迫**​ | 用户被产品逻辑推着走，缺少选择权。 |
| **束缚**​ | 产品限制过多，行动和感受被压缩。  |

## E-6 仪式与完成

**Ritual & Completion**

产品将普通动作转化为有秩序、有期待、有完成感的过程。

| 关键词     | 释义                   |
| ------- | -------------------- |
| **仪式**​ | 使用过程具有开始、进行、结束的情绪秩序。 |
| **期待**​ | 使用前或使用中产生正向等待感。      |
| **完成**​ | 结束时感到事情被妥善完成。        |
| **机械**​ | 使用过程只是重复动作，缺少情绪意义。   |
| **琐碎**​ | 使用过程细节过多，情绪被消耗。      |
| **敷衍**​ | 过程缺少设计感，像是随便完成。      |

## E-7 沉浸与连续

**Immersion & Flow**

产品帮助用户进入专注、投入、连续的使用状态。

| 关键词     | 释义              |
| ------- | --------------- |
| **沉浸**​ | 注意力自然进入产品或场景中。  |
| **专注**​ | 使用中不容易分心。       |
| **连续**​ | 使用感受不断裂，状态自然延续。 |
| **打断**​ | 产品行为破坏用户当前状态。   |
| **分心**​ | 使用中注意力被反复拉走。    |
| **跳脱**​ | 产品反馈让用户从情境中被抽离。 |

## E-9 疗愈与修复

**Healing & Recovery**

产品在使用过程中带来安抚、恢复、温暖或心理修复感。

| 关键词     | 释义              |
| ------- | --------------- |
| **疗愈**​ | 使用中感到被安抚和修复。    |
| **抚慰**​ | 产品反馈缓解负面情绪。     |
| **恢复**​ | 使用后身心状态有所回升。    |
| **耗竭**​ | 使用过程消耗心理或身体能量。  |
| **疲惫**​ | 产品让用户感到累、麻烦或负担。 |
| **烦扰**​ | 产品持续制造不必要的刺激。   |
